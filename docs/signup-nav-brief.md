# 브리프: 등록 전 빈칸 채우기와 세 페이지 칩

대상 레포: `website` (커밋 `907abc0` 기준). 근거는 `docs/signup-review-2026-10-12.md`(S1~S15, N1~N8). 정본은 `docs/brand.md`(먼저 읽습니다). 바꾸는 파일은 `data/naru.ts`, `data/crossingForm.ts`, `components/crossing/*`(등록 모달), `components/journey/JourneyNav.tsx`(세 페이지 헤더), `data/dictionaryCore.ts`, 푸터 컴포넌트. 챕터 순서, 블록 자리, 글자 크기, 배경, `/quiz`, `/match`, API, Supabase는 건드리지 않습니다. 체인지로그는 `CLAUDE.md` 규칙대로.

두 단계입니다. 1단계는 글과 버튼 스타일만, 2단계는 헤더 칩. 단계마다 사용자가 스크린숏을 확인한 뒤 다음으로.

## 0. 결론 한 줄

**학생이 멈추는 빈칸 셋(언제, 얼마, 혼자 가도 되나)을 첫 화면 안에서 채우고, 미리 보기 폼이 "지금 써 두면 남는다"를 말하게 하고, 세 페이지 헤더 같은 자리에 같은 칩 셋을 둡니다.**

### 1.2 등록 미오픈 안내 세 곳을 같은 문장으로 (S1, S2, S3, S7, S9)

히어로 안내(`#hero-register-note`), 등록 블록 문단(`#december-register-note`), 모달 상단 안내 박스가 같은 키(`registerNote`)를 읽게 합니다. 문장:


EN도 같은 구조로. 등록 블록의 "전공과 코딩 경험은 참가 조건이 아닙니다. 스크리닝 없이, 오는 사람이 참가자입니다."는 둘째 문장만 남깁니다(스크리닝 없음은 홈에 한 번, 정본 9장). 히어로는 첫 두 줄만, 등록 블록과 모달은 네 줄 전부.

## 2단계. 세 페이지 헤더 (N1~N8)

### 2.1 페이지 칩 셋

세 페이지(`/`, `/naru`, `/2026-08`) 헤더의 로고 바로 오른쪽, 같은 자리에 칩 셋: **크로싱 서울 / 나루 / 8월 기록** (EN: Crossing Seoul / NARU / Aug 2026). 순서 고정, 현재 페이지 칩만 채움(`aria-current="page"`, `bg-accent/[0.12] border-accent/40`), 나머지 `bg-white/[0.04] border-white/15`. 화살표 없음. 목적지는 각 페이지 맨 위(`/`, `/naru`, `/2026-08`). `/naru`의 "← 크로싱 서울" 알약과 `/2026-08` 헤더의 "12월 이벤트 →" 알약, 그 아래 스트립의 버튼 둘은 뺍니다(스트립 문장은 유지). 챕터 칩(프로그램, 등록 / 코어, 함께하기, 왜 / 프로그램, 연사, 멘토링, 파트너, FAQ)은 페이지 칩 오른쪽에 24px 띄우고 지금 스타일대로.

### 2.2 폰 레일

레일을 스크롤 0부터 보입니다(헤더 두 줄). 레일 = [페이지 칩 셋] 1px 구분선 [챕터 칩]. 왼쪽 정렬, 13.5px, nowrap, 기존 마스크 스크롤. `/2026-08`의 고정폭 칩과 오른쪽 고정 "12월 이벤트" 핀은 뺍니다. 폰 히어로 버튼 하단이 844 안에 남는지 확인(실측 604 예상).

### 2.3 링크 정리

- 홈 헤더 "나루" → `/naru`(티저 `#naru` 챕터는 그대로 둠). "참가" 칩 라벨은 "등록" / "Register", 목적지 `#register`는 유지하되 id를 블록 제목(h3 "등록")으로 올리고 `scroll-margin-top`을 헤더 높이만큼.
- `/2026-08`에서 홈으로 가는 링크 넷 중 라벨에 "프로그램"이 있는 하나만 `/#december`, 나머지는 `/`. "8일의 사진과 이야기는 나루 홈에 →"는 `/`로, 라벨 "8일의 사진은 크로싱 서울 홈에 →".
- `/2026-08` 헤더: 알약 색을 본 사이트 accent 계열로, EN KR 두 버튼으로, 푸터 저작권 "© 2026 나루 NARU"(주최 AXMOS 문구는 감사 섹션에 그대로). 로고는 그대로.
- 세 페이지 푸터에 같은 한 줄: 크로싱 서울 / 나루 / 제로백 빌더톤 8월 기록 + 오픈채팅 + 문의.
- 본문 인라인 링크 스타일 하나로(밑줄). 히어로 "나루" 인라인 링크는 뺍니다(헤더 칩과 티저 버튼이 있음).
- EN: "Programme"/"Program" 혼용은 정본대로 programme, "Dec event" 삭제.
