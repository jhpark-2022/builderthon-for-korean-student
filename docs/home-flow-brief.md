# 홈 흐름 재배치 브리프: 히어로 아래에 사진 대신 답을 둔다

Claude Code용. 커밋 `8d3ecb1`(2026-09-17, 히어로 사진 넷) 이후의 나루 홈(`/`)을 고친다. 그룹 챕터(`#naru`, `#how`, `#join`, `#people`, `#closing`)와 `/2026-08`은 손대지 않는다.

## 0. 문제와 결정

지금 흐름: 히어로(12월 + 8월 사진 4장) → 8월의 기록(숫자 + 사진 6장 + 언론) → 프로그램 → 나루 → 학생회와 기업 → 함께.

두 가지가 어긋난다. 사진이 연달아 두 번 나오고, 시간이 12월 → 8월 → 12월로 오간다.

결정(사용자, 2026-09-17): **히어로의 사진은 남긴다.** 그 아래는 사진이 아니라, 히어로를 본 사람이 묻는 순서대로 답한다. 무엇을 하는가 → 무엇이 남는가 → 그게 진짜인가 → 누가 만드는가.

```
전                         후
#top      크로싱 서울        #top       크로싱 서울 (그대로)
#record   8월의 기록         #december  닷새의 모양 (지금의 프로그램 챕터를 그대로 올림)
#december 프로그램           #gains     오면 무엇이 남는가 (신설. 제목 다섯, 디테일 없음)
#naru     나루              #record    8월이 남긴 것 (사진 벽 삭제. 숫자 + 사람 + 언론 + 아카이브)
#how      학생회와 기업       #naru      나루 (그대로)
#join     함께              #how       학생회와 기업 (그대로)
                            #join      함께 (그대로)
```

## 1. 챕터별 작업

### 1.1 `#december` 닷새의 모양 (히어로 바로 아래로)

- 챕터 내용은 지금 그대로(H2, 리드, `notSequel`, 아쉬웠던 넷과 12월의 답, 일정 카드 5, 워크샵 상자 3, General Mentoring 상자, 재는 것, 미정 목록, 문). **순서만 히어로 다음으로.** 카피 키를 바꾸지 않는다.
- 히어로의 주 CTA "프로그램 보기 ↓"가 이 챕터에 착지한다. 앵커 `#december`는 그대로.
- 270px 이음매(이벤트 → 그룹)는 `#naru` 앞에 그대로 남는다. 옮기지 않는다.

### 1.2 `#gains` 오면 무엇이 남는가 (신설)

8월 사이트의 "참가하면 무엇을 얻나요?" 자리다. 지금 홈에 없는 챕터.

- 아이브로 `emerald`(8월 "참가 혜택" 필과 같은 색), H2 "오면 무엇이 남는가", 리드 없음.
- 카드 다섯. **제목만 쓴다. 본문도 불릿도 없다.** 사용자가 정한 다섯 줄 그대로:

  | 번호 | ko | en |
  | --- | --- | --- |
  | 01 | 실명 기업의 진짜 문제 | A real problem from a named company |
  | 02 | 멘토 | Mentors |
  | 03 | 앞에서 증명 | Proving it out front |
  | 04 | 무순위 어워드 | Awards with no ranking |
  | 05 | 국경 너머의 동료 | Peers from across the border |

  영문은 초안이다(`TODO: confirm`). 한글이 정본.
- 카드 문법은 8월 `BenefitCard`(번호 배지 + 제목). 데스크톱은 한 줄 다섯(숫자 스탯 행과 같은 그리드), 폰은 두 열 + 마지막 한 장 전폭. 카드 높이는 제목 한 줄 기준으로 낮게. 비어 보이면 안 되고 꽉 차 보여도 안 된다. 제목 크기는 `H3`.
- 카드 아래 한 줄: "디테일은 확정되는 대로 이 자리에서 공개합니다." / "Details go here as they are confirmed." `text-white/50`. 이 한 줄이 "왜 제목뿐인가"에 대한 답이다.
- **지어 넣지 않는다.** 8월의 수치, 멘토 수, 어워드 부문, 기업 이름을 카드에 붙이지 않는다. 사용자가 제목만 쓰라고 했다.
- 새 키 `data/naru.ts`의 `gains: { eyebrow, heading, items[5]{ num, title }, note }`. `naruNav`에 항목 추가.

### 1.3 `#record` 8월이 남긴 것 (증거로 바꾼다)

- H2를 "8월에 있었던 일"에서 **"8월이 남긴 것"**(en "What August left behind")으로. 아이브로와 리드는 그대로.
- **사진 벽(`PhotoWall`, `record.wall`)을 이 챕터에서 뺀다.** 사진은 히어로가 한다. 같은 사진을 두 번 걸지 않는다는 규칙 그대로. 파일과 `record.photos` 키는 지우지 않는다(히어로 넷과 원본이 겹치지 않는지 확인은 이미 돼 있다).
- 남기는 순서: 숫자 다섯(`StatRow`) → **사람**(`RecordTabs`, 아래) → 언론 줄(`PressRows`) → 아카이브 버튼(2차 유령 필).
- `RecordTabs`는 9/16에 화면에서 내려갔지만 파일이 그대로 있다. 되살리되 **탭 둘만**: 멘토(11명, 링크드인) / 연사와 피드백 패널(3 + 3 + 8, 링크드인, 패널 사진). "8일의 형식" 탭은 켜지 않는다(아카이브가 정본이고 여기서는 길이만 늘린다). 탭 키보드 패턴, 배열 길이에서 세는 숫자, 8월 정본 직접 읽기는 9/15 체인지로그 §2.9 그대로.
- 이 챕터가 하는 말은 "실명이 박힌 진짜 사람들이 왔다"이다. 갤러리가 아니다.

### 1.5 배경 국면

`lib/background`의 국면 경계가 `#record`, `#december` 앵커의 offsetTop을 읽는다. 챕터 순서가 바뀌었으니 매핑을 다시 맞춘다: banks = 히어로, gather = `#december` 시작, crossing = `#december` 본문 ~ `#gains`, arrived = `#record`부터. 형상은 꺼져 있고(`SHAPES.enabled = false`) 깊이 층만 있으니 화면 변화는 거의 없지만, 앵커를 못 찾아 국면이 멈추는 일은 없어야 한다.
