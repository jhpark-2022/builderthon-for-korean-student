# 배경 WebGL: 나루 심볼(섬과 점) 하나로

Claude Code용. 커밋 `8d3ecb1` 이후(형상 꺼짐, 깊이 층만) 상태에서 시작한다. `docs/background-shapes-brief.md`와 `docs/background-fix-brief.md`의 싱가포르·서울 두 형상 부분은 **이 파일로 대체**한다. 깊이 층(8월 필드 35%)과 8월 페이지의 `field` 경로는 그대로.

---

## 0. 결정 (사용자, 2026-09-18)

배경은 **기존의 나루 이미지**, 즉 로고 심볼(`public/naru/naru-symbol.svg`: 섬 윤곽 + 남쪽 해안의 주황 점)이다. 싱가포르·서울 두 형상은 쓰지 않는다. 입자가 나루 심볼 하나를 그리고, 심볼의 주황 점이 곧 등불이다. 화면의 주황은 여전히 이 점 하나.

## 1. 장면

- **형상 하나.** 이미 구워 둔 `lib/background/shapes/singapore.ts`(로고 섬 패스, 21 꼭짓점, 2,000점)를 그대로 쓴다. `seoul.ts`는 로드하지 않는다(파일은 둔다).
- **나루 점.** SVG의 `circle cx=84.2 cy=107.5`(패스 좌표계, `translate(180,180) scale(2.2) translate(-80,-80)` 변환 전)를 같은 정규화로 점 좌표에 넣는다(`scripts/build-shape-points.py`에 `--point` 출력 추가, `singapore.ts`에 `NARU_POINT: [x, y]` export). 등불(`Atmosphere`의 점광 + 블룸)을 **이 좌표에** 세운다. 지금의 등불 위치 상수는 버린다.
- **자리: 히어로 뒤 전체 폭 워터마크.** 심볼을 뷰포트 가운데(x 50%, y 52%)에 너비 **72vw**(데스크톱), **110vw**(폰, 좌우로 살짝 넘침)로 세운다. 기울기 0°, 정면. 카피와 사진 뒤에 깔리는 것이 의도다. 그래서 밝기는 낮다: 가장자리 점 0.45, 속 점 0.15(fix 브리프의 1.0 / 0.35 대신). 점 크기는 fix 브리프 그대로(2.8 / 1.4). 윤곽을 따라 도는 빛의 파도(12초) 유지.
- **DOM 앵커, 라벨, 무대, 감광 규칙은 전부 뺀다.** 뷰포트 기준 좌표 하나뿐이다. `placeShapes()`는 리사이즈에서만 다시 잰다.
- 히어로 사진 넷 위에 로고를 얹는 것이 아니다. 사진은 DOM에서 캔버스보다 앞에 있고 불투명하니 사진 영역에서는 배경이 가려진다. 로고 가이드의 "사진 위에 얹지 않음"은 이 경우 지켜진다(뒤에 있는 것이지 위에 있는 것이 아니다). 다만 사진 사이 틈으로 보이는 점들이 지저분하지 않은지 스크린샷으로 본다.

## 2. 국면

```
banks     히어로가 화면에 있는 동안. 심볼 정지(숨 진폭 30%), 나루 점 켬.
gather    히어로 하단이 뷰포트 상단을 지나면 0.4화면에 걸쳐 속부터 풀리고 가장자리가 마지막에. 점은 0.6화면에 걸쳐 꺼진다.
crossing  #december ~ #gains 본문. 점들이 깊이 층 안으로 들어가 화면 중심 뒤쪽으로 흐른다(지금 구현 그대로).
arrived   #naru 챕터(그룹의 시작)부터. 점들이 **다시 심볼로 모인다.** 뷰포트 가운데, 너비 90vw, 밝기는 banks의 50%, 나루 점은 켜되 블룸 절반. #naru의 로고 PNG와 태그라인 뒤에서 큰 섬이 희미하게 서 있는 그림이다. 이후 #how, #join에서는 그대로 두되 스크롤에 따라 아주 천천히 드리프트(형상 유지).
```

- 국면 경계는 앵커 offsetTop에서 읽는다(홈 흐름 재배치 브리프의 새 순서 `top → december → gains → record → naru → how → join` 기준).
- 정지 토글은 banks 상태로 얼어붙는다. 정지 화면 = 나루 심볼.

## 3. 하지 않는 것

- 싱가포르·서울 두 형상, 라벨, 강 반사 띠, 화면 폭 수평선.
- 심볼의 외곽선 실선, 면 채우기, 두 번째 주황 점.
- 8월 `field` 경로 변경(`/2026-08` 픽셀 diff 0).
- 히어로 DOM 변경(사진 넷, 카피, CTA, 카운트다운 패널 그대로).

## 4. 검증 (움직임 켠 실제 브라우저, 로드 후 6초)

1. `npx tsc --noEmit`, `npm run build`, 콘솔 오류 0.
2. 1280×720, 1440×900, 1920×1080, 2000×1100, 390×844에서 스크롤 0 스크린샷. 심볼의 바운딩 박스 중심이 뷰포트 높이의 45~58%에 있고, 로고 가이드의 섬과 같은 윤곽으로 읽히며, 주황 점이 남쪽 해안 그 자리에 있어야 한다. `.shots/naru/bg-symbol/compare.png`에 로고 심볼과 나란히.
3. 카피 뒤 휘도: 히어로 H1과 서술 영역의 캔버스 평균 상대 휘도가 이전 체인지로그 기준(0.0045)을 넘지 않을 것. 넘으면 가장자리 밝기부터 내린다.
4. `#naru` 첫 화면(스크롤 → `#naru` offsetTop)에서 심볼이 다시 서 있는지, 태그라인 두 줄의 대비가 유지되는지.
5. 스크롤 900 / 2000 / 3600 / 6000에서 화면 폭을 가로지르는 밝은 줄 없음(행별 휘도 검사, fix 브리프 4번과 같은 스크립트).
6. fps 60(1440), 45+(폰). `/2026-08` 픽셀 diff 0.
7. 체인지로그 `docs/changelogs/changelog-september-XX-2026-bg-symbol.md`. 커밋 `feat(bg): 배경 입자를 나루 심볼 하나로 세운다`. `main` 푸시 전에 1~6, 특히 2번은 다섯 해상도 전부.
