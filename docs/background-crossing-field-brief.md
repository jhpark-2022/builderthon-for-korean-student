# 배경 WebGL: "건너는 점들" (Crossing Field) 브리프

Claude Code용. `docs/august-design-language-brief.md`와 같이 쓰거나 그 뒤에 이어서 한다. 대상은 나루 홈(`/`)의 배경 하나. `/2026-08`의 입자 필드는 손대지 않는다.

---

## 0. 한 줄 목표

8월의 GPU 입자 필드(`ParticleField` + `PostFX` 블룸 + 스크롤 국면)를 그대로 엔진으로 쓰되, 이야기를 "중력 포털"에서 **"강을 건너는 점들"**로 바꾼다. 양쪽 기슭에 흩어져 있던 점들이 스크롤에 따라 어두운 강을 건너 등불 하나(나루 점) 쪽으로 모인다. 지금의 수면 셰이더(`shaders/water.ts`)는 강 띠의 얇은 반사로만 남긴다.

## 1. 왜 이것인가

- **8월과 같은 엔진.** `lib/background/particles/ParticleField.ts`, `renderer/PostFX.ts`(블룸), `camera/CameraController.ts`(3° 포인터 패럴랙스, 스크롤 돌리), `utils/phases.ts`(국면), `config.ts`(기기별 품질 티어)를 전부 재사용한다. 새로 쓰는 것은 입자의 초기 분포, 흐름장, 국면 곡선, 등불 한 점이다. 8월이 "쿨했던" 이유(블룸 입자, 깊이, 스크롤에 반응)가 그대로 온다.
- **나루의 이야기다.** 건너는 건 각자가 한다(입자 하나하나가 건넌다). 자리는 우리가 만든다(등불 한 점). 8월(한 기슭) → 12월(양쪽 기슭에서). 로고의 주황 점이 배경에서 등불로 서 있다.
- **이미 튜닝돼 있다.** 품질 티어(폰 900 / 데스크톱 2,800~4,000, 폰은 블룸 없음), `motionScale` 0(정지 토글, `prefers-reduced-motion`), 9/15의 NaN 함정 기록까지 그대로 쓴다.

검토했다가 뺀 것: 유체 시뮬레이션(포인터 잉크. 멋있지만 무겁고 어디서나 보는 것이며 주황이 면으로 번진다), 등고선 지형(로고 섬을 등고선으로. 우아하지만 정적), 리본 항적(선 기반. 별도 엔진이 필요해 8월과 결이 갈린다).

## 2. 장면

- **기슭 둘.** 화면 왼쪽 30%와 오른쪽 30% 깊이 공간에 입자가 흩어져 있다. 두 기슭의 입자 수는 같다(어느 쪽이 주인공이 아니다).
- **강.** 가운데 40%는 입자가 없고 어둡다. 강 표면에는 지금 `water.ts`의 반사 기둥과 잔물결 중 **얇은 띠 하나**만 남긴다(지평선 아래 1/3, 화면 폭 전체, 높이는 뷰포트의 12~15%). 수면 셰이더의 나머지(하늘, 등불 원본)는 끈다.
- **등불 한 점.** 강 건너편(z 깊이 먼 쪽) 가운데 조금 왼쪽에 `PALETTE.hi1`(주황) 점광 하나. 블룸이 이 점만 뜨겁게 잡는다. 화면에서 주황은 이 점과 그 반사 기둥뿐이다(9/15 원칙 유지).
- **흐름장.** 컬 노이즈(이미 `noise.glsl.ts`에 있음)에 등불 쪽으로 약한 인력을 더한다. 인력의 세기가 국면 `pull`이다. 입자는 각자 다른 속도로 건넌다(속도에 개체 편차 ±40%). 먼저 건넌 점이 있고 늦게 건너는 점이 있다는 것이 화면에 보여야 한다.
- **색.** 기슭의 입자는 `accent0~accent2`(보라~자주). 강을 건너는 동안 `hi0`(연자주)로 밝아지고, 건너편에 닿으면 다시 가라앉아 등불 주변의 잔잔한 성좌가 된다. 입자가 주황이 되지는 않는다.

## 3. 스크롤 국면 (`utils/phases.ts`를 홈 전용으로 분기)

```
0.00–0.15  banks     기슭에서 느리게 떠다닌다. 등불은 멀리 희미하게. (히어로)
0.15–0.45  gather    기슭의 점들이 강가로 모인다. 등불이 또렷해진다. (8월의 기록)
0.45–0.75  crossing  강을 건넌다. 트레일이 길어지고 블룸이 오른다. 반사 띠가 흔들린다. (프로그램)
0.75–1.00  arrived   건너편에 닿아 등불 둘레의 성좌로 가라앉는다. 카메라 돌리 멈춤. (나루, 학생회와 기업, 함께)
```

- 8월의 `portal`, `whiteout`은 쓰지 않는다. 화이트아웃 없음.
- 국면 경계는 챕터 앵커의 실제 스크롤 위치에서 읽는다(`document.querySelector("#december")` 등의 offsetTop / scrollHeight). 페이지 길이가 바뀌어도 "프로그램에서 건넌다"가 유지된다. 상수로 박지 않는다.
- 그룹 챕터(`#naru` 이후)에서는 배경이 거의 정지에 가깝게 잔잔해야 한다. 코어 판 두 장 뒤에서 움직이는 것은 방해다.

## 4. 구현 지침

- `lib/background/scene/BackgroundScene.ts`의 `variant`에 `"crossing"`을 추가한다. `"field"`(8월)와 `"water"`(지금)는 그대로 둔다. `app/page.tsx`는 `variant="crossing"`.
- 입자 초기 분포: `ParticleField.ts`의 초기화 함수를 variant별로 분기. crossing은 x를 두 기슭에 이봉 분포, z는 깊이 전체, y는 지평선 근처에 집중(가우시안).
- 흐름장은 `particles.vert.ts`에 uniform 셋 추가: `uLantern`(vec3), `uPull`(float), `uCrossing`(float). 기존 uniform 이름은 바꾸지 않는다(8월 셰이더가 같은 파일을 읽는다면 variant 분기 또는 파일 복제 중 **분기**를 택한다. 8월 페이지 픽셀 diff 0이 조건).
- 등불: `Atmosphere.ts`의 점광 또는 스프라이트 하나. 블룸 임계값은 등불만 넘고 입자는 넘지 않게(`PostFX` threshold를 variant별로).
- 강 반사 띠: `water/WaterSurface.ts`를 높이·위치 prop으로 얇게 만들어 재사용. 새 셰이더를 쓰지 않는다. `max(H - p.y, 0.0)` NaN 가드 유지.
- 품질 티어: `config.ts`의 `pickQuality` 그대로. 폰은 블룸 없음이므로 등불은 스프라이트에 방사 그라데이션을 구워 블룸 없이도 빛나게 한다.
- 정지: `motionScale` 0에서 입자·반사·카메라 전부 얼어붙는다(9/15 `fieldTime` 누산기 방식). `MotionToggle`은 그대로 작동해야 한다.
- 성능 목표: 1440에서 60fps, 폰(iPhone 12급)에서 45fps 이상. `requestAnimationFrame` 안에서 `performance.now()` 델타로 10초 측정해 체인지로그에 적는다. 미달이면 입자 수부터 줄인다.
- 캔버스는 지금처럼 fixed. 그룹 챕터 뒤에서 잔잔해지는 것은 국면으로 하고, 9/15처럼 "지평선을 가라앉히는" 트릭은 쓰지 않는다(건너편에 닿는 장면이 필요하다).

## 5. 하지 않는 것

- 8월 페이지의 배경 변경. `variant="field"` 경로의 파일 diff는 0이어야 한다.
- 주황 입자, 주황 면, 두 번째 등불.
- 화이트아웃, 카메라 급가속, 포인터에 따라 입자가 튀는 효과(8월도 3° 패럴랙스뿐).
- 히어로 영상.

## 6. 검증

1. `npx tsc --noEmit`, `npm run build`, 콘솔 오류 0(셰이더 컴파일 경고 포함).
2. `/2026-08` 전후 스크린샷 픽셀 diff 0.
3. 스크린샷 `.shots/naru/bg-crossing/`: 1440·390에서 스크롤 0 / 0.3 / 0.6 / 0.9 지점 각각(입자가 실제로 기슭 → 강 → 건너편으로 옮겨 가는 것이 네 장에서 읽혀야 한다).
4. 정지 토글 켠 상태 스크린샷 두 장(같은 지점 3초 간격, 픽셀 diff 0).
5. fps 측정값(데스크톱, 폰 시뮬레이션 또는 실기기) 체인지로그에.
6. 텍스트 대비: 히어로 H1과 코어 판의 본문 뒤에서 배경 휘도가 8월 히어로 뒤보다 높지 않을 것(스크린샷의 해당 영역 평균 휘도 비교). 넘으면 `intensity`를 내린다.
7. 체인지로그 `docs/changelogs/changelog-september-XX-2026-bg-crossing.md`. 커밋 `feat(bg): 배경을 건너는 점들로 바꾼다`. `main` 푸시 전에 1~6.
