## 0. 지금 (실측 2026-11-16, HEAD 2fdd876. naru.community도 같음)

| 자리 | 지금 |

## 1. 뒤

| # | 바꿈 |
| --- | --- |
| R1 | 관찰하는 요소에 clip-path를 두지 않음. `DetailRow`의 바깥 `div`(ref, `data-shown`)는 opacity, transform, blur만 갖고, 위에서 아래로 열리는 clip-path는 그 안의 `dt`와 `dd`가 `group-data-[shown=true]`로 받음(다른 방법도 되지만 `dl > div > dt, dd` 구조는 그대로). 줄의 어느 부분이든 화면 위쪽 78% 안에 들어오면 나타남 |
| R2 | 한 번 나타난 것은 다시 숨기지 않음. `useReveal`에서 `leave`를 빼고, 켜진 뒤에는 관찰을 끊음(`RevealGroup`과 같은 방식). `TypeHeading`도 한 번만 쳐짐 |

## 2. 지키는 것

- 천천히 내려올 때의 모양은 전과 같습니다. 줄은 위에서 아래로 열리며 또렷해지고(1000ms), 항목은 700ms, 단계 이름은 한 글자씩, 정거장은 한 번 커졌다 돌아옵니다. 시간과 곡선 값은 바꾸지 않습니다.
- 움직임을 끈 사람(`prefers-reduced-motion`, `html[data-motion=off]`)에게는 지금처럼 처음부터 다 보입니다.
- IntersectionObserver가 없는 브라우저는 지금처럼 바로 보입니다.
- 등록 서버(`app/api/crossing/register`), `lib/registrationWindow.ts`, Supabase는 건드리지 않습니다.
- 다른 페이지와 `RevealGroup`, `RevealItem`의 클래스는 그대로입니다.

## 3. 결정

- D1 R2는 점검의 권고(한 번 나타나면 그대로)를 따른 것입니다. 오르내릴 때마다 다시 나타나는 연출을 남기려면 R2만 빼면 되고, 빈 화면은 R1만으로 없어집니다.
- D2 등장에 걸리는 시간(약 1초)은 이 브리프에서 줄이지 않습니다. 줄이는 것은 사용자 결정 뒤에 따로 합니다.
