# 브리프: 글은 그대로, 자리만 당겨서 빈 느낌 없애기

대상 레포: `website` (`7b95fac`, 배포본과 같음). 정본은 `docs/brand.md`(먼저 읽습니다). **문장, 로고, 그림을 더하지 않습니다.** 지금 있는 것의 자리와 간격만 바꿉니다. 챕터 순서(히어로 → 프로그램 → 남는 것 → 함께하는 곳)는 그대로이고, 바뀌는 것은 챕터 안의 배치입니다. 폰(390)은 지금 밀도가 괜찮아서 **데스크톱(lg 이상)만** 손댑니다. 폰 레이아웃은 바꾸지 않습니다.

## 0. 실측: 왜 비어 보이나

화면(900px) 단위로 글·그림·버튼이 덮는 면적을 쟀습니다(8px 격자).

| 화면 | y | 데스크톱 채움 | 가장 긴 빈 세로 | 폰 채움 |
| --- | --- | --- | --- | --- |
| 0 히어로 | 0 | 45% | 120px | 40% |
| 1 프로그램 제목, 노선도 | 900 | 20% | 200px | 51% |
| 2 Day 카드 | 1800 | 24% | 120px | 41% |
| 3 Day 4, 큐레이션 두 열 | 2700 | 27% | 104px | 41% |
| 4 네 질문, 기업의 닷새, 등록 | 3600 | **14%** | **328px** | 32% |
| 5 남는 것 | 4500 | 18% | 112px | 35% |
| 6 남는 것 표, 함께하는 곳 | 5400 | **13%** | **264px** | 30% |
| 7 로고 줄 | 6300 | **5%** | 120px | 15% |

폰은 30~50%, 데스크톱은 13~27%입니다. 글을 줄인 건 맞는데 **그릇은 글이 많던 때 크기 그대로**라서 생긴 일입니다. 큰 그릇 넷:

| 그릇 | 높이 | 안에 있는 것 |
| --- | --- | --- |
| 큐레이션 두 열 (왼쪽 열) | 약 500px | 숫자 둘("5일", "무순위") |
| 남는 것 시간표 카드 | 약 1,100px | 문장 다섯 + 막대 다섯. 5열 격자의 80%가 빈 칸 |
| 함께하는 곳 | 1,423px | 로고 13개를 5줄로, 줄마다 하단선과 96px 여백 |
| 프로그램 판 끝 ~ 남는 것 제목 | 약 300px | 판 여백 + 챕터 틈(배경 형상 자리) |

## 1. 바꾸는 것 (데스크톱만)

| # | 블록 | 지금 | 뒤 | 높이 |
| --- | --- | --- | --- | --- |
| 1.1 | 큐레이션 두 열 | 왼쪽 열 세로로 "5일", "무순위" 거대 숫자 + 가는 선, 오른쪽 열 dl 표 셋 | 한 열로. 맨 위 한 줄 "과정 지향적인 이벤트를 큐레이션합니다" 그대로, 그 아래 **숫자 둘을 한 행에 나란히**(TITLE 숫자 + BODY 라벨, 왼쪽 정렬), 그 아래 **팀 구성 / 공간 / 미션을 3열**로(dt 위, dd 아래). 숫자 굵기는 `font-bold text-white/85`(10/15 리뷰 H4) | 약 500 → 280px |
| 1.2 | Day 카드 | Day 0 전폭, Day 1~3 3열, Day 4 전폭 | **Day 0~3을 4열**(Day 0 카드는 본문 한 줄과 칩이라 다른 셋과 높이가 맞음), Day 4는 전폭 유지(인기투표 버튼이 있어 마무리 역할). 카드 안쪽 패딩 `py-[27px]` → `py-[20px]` | 약 1,100 → 820px |
| 1.3 | 남는 것 | 척추 카드(문장 하나) + 시간표 카드(5열 격자, 막대) | 척추 카드를 없애고 그 문장을 H2 아래 리드로(카드 없이, 지금 프로그램 제목 아래 리드와 같은 문법). 시간표는 유지하되 **막대 격자 폭을 전체의 45% → 30%**, 행 패딩 `py-[22.5px]` → `py-[16px]`, 격자 바탕 띠(`bg-white/[0.03]`) 제거 | 약 1,300 → 850px |
| 1.4 | 함께하는 곳 | 5줄(메인 후원 / 장소 / 기술 / 커뮤니티 / 주최), 줄마다 `py-[48px]` + 하단선 | **2줄**. 1줄 = 메인 후원(AXMOS + 코어 5개사 테두리, 지금 그대로). 2줄 = 장소, 기술·크레딧, 커뮤니티·홍보를 **한 줄에 세 묶음**으로 나란히(묶음마다 META 라벨 위, 로고 아래, 묶음 사이 세로 구분선). 주최 나루 + "나루 알아보기"는 2줄 맨 오른쪽 네 번째 묶음. 섹션 패딩 `lg:pt-[108px] lg:pb-[126px]` → `lg:pt-[72px] lg:pb-[72px]` | 1,423 → 약 650px |
| 1.5 | 네 질문 + 기업의 닷새 | 4열 표, 그 아래 3열 표, 각각 위아래 48px | 두 표 사이 간격 48 → 32px. 표 자체는 그대로 | 약 -40px |
| 1.6 | 판 끝 ~ 다음 챕터 | 프로그램 판 바닥 여백 + 챕터 틈 약 300px | 판 안쪽 바닥 패딩만 줄임(등록 CTA 아래 `pb` 약 90 → 56px). **챕터 틈 자체는 그대로**(배경 형상이 보이는 자리, 2026-09-26 결정) | 약 -35px |
| 1.7 | 히어로, 카운트다운 | | 그대로 | |

합치면 데스크톱 문서 높이 7,501 → 약 6,000px(-20%), 화면 4·6·7의 채움이 14/13/5% → 25% 이상.

## 2. 하지 않는 것

새 문장, 새 로고, 새 그림, 색 변경, 글자 크기 변경, 챕터 순서 변경, 폰 레이아웃 변경, 노선도 모양 변경, 카드 테두리 문법 변경. 글이 줄어 생긴 빈자리를 **채우지 않고 당깁니다.** 10/11에 되돌린 재배치는 챕터 순서였고, 이번은 챕터 안의 열 수와 패딩입니다.
