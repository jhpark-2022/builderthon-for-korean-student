# Changelog 2026-09-19 (폰 배경을 데스크톱과 같은 순서로)

**Project:** 나루 NARU 사이트 (Next.js)
**Branch:** `main`
**Scope:** `lib/background/scene/BackgroundScene.ts`의 `water` 분기 한 곳과 `lib/background/config.ts`의
주석. 8월 페이지의 `field` 경로, `crossing` 경로, 화면 카피, 레이아웃은 건드리지 않았습니다.

## 1. 한 것

사용자: "모바일 뷰를 보니까 처음부터 서울 윤곽이 보이고 해만 있더라. 데스크톱이랑 배경 효과가
동일했으면 좋겠어. 나루 이미지가 보이고, 내려가면서 서울 윤곽 점들이 빛나는 걸로."

가로 화면과 세로 화면이 **서로 반대 순서**로 그려지고 있었습니다.

| | 히어로 | 히어로 이후 | #naru부터 |
| --- | --- | --- | --- |
| 가로(전) | 서울 윤곽 없음(물과 해만) | `revealVh`(0.8화면)에 걸쳐 떠오름 | 밝기 0.6배 |
| 세로(전) | **110vw 서울 윤곽, 밝기 0.8** | 0.4화면에 걸쳐 풀려 사라짐 | 90vw·0.5로 다시 |
| 세로(후) | 없음(가로와 같음) | `revealVh`에 걸쳐 떠오름 | 90vw·0.5로 어두워짐 |

세로 화면의 그 배치는 9월 18일 모바일 수정 브리프(6.1·6.5)의 결정이었습니다. 폰에서는 히어로가
길어서 배경이 오래 비어 보인다는 이유였는데, 그 대가로 첫 화면이 물과 해가 아니라 서울 윤곽이
되었고 두 화면 크기의 순서가 반대가 됐습니다.

- 이제 세로도 `revealVh` 곡선 하나를 씁니다. 히어로에서는 입자가 아예 그려지지 않습니다
  (`points.visible = opacity > 0.001`).
- 세로에 남은 차이는 **크기와 밝기뿐**입니다. 심볼이 110vw → 90vw로 좁아지고(스크롤에 따라),
  밝기는 0.8 → 0.5. 폰에서 전체 밝기(1.0)면 카피 뒤가 시끄럽습니다.
- `SEOUL_WATERMARK.portrait.dissolveVh`는 더 이상 쓰이지 않습니다. 키는 되살릴 때를 위해 둡니다.

## 2. 검증

| 항목 | 기준 | 결과 |
| --- | --- | --- |
| 타입·빌드 | `tsc --noEmit`, `npm run build` | 통과 |
| 폰 첫 화면 | 390×844, 스크롤 0 | 물과 해만. 서울 윤곽 없음 |
| 폰 스크롤 | 히어로 끝 + 0.6화면 | 서울 윤곽 점들이 본문 뒤에 떠 있음 |
| 데스크톱 | 1440×900, 스크롤 0 | 전과 같음(물과 해만) |
| 8월 페이지 | `field` 경로 | 코드 경로를 건드리지 않음 |

## 3. 남은 것

- 세로에서 `#naru` 이후의 밝기(0.5)와 너비(90vw)는 9/18 값을 그대로 씁니다. 더 어둡게 하려면
  `SEOUL_WATERMARK.portrait.naruBright`만 내리세요.
- 저사양 기기에서 세로 입자 수는 500(`points.phone`)입니다. 히어로에서 그리지 않게 되면서
  첫 화면의 GPU 부담은 오히려 줄었습니다.
