## 1. 문제

히어로(12월 + 8월 사진 넷) 바로 아래에 8월의 기록(숫자 + 사진 여섯 + 언론)이 왔습니다.
사진이 연달아 두 번 나오고, 시간이 12월 → 8월 → 12월로 오갔습니다.

## 2. 결정 (사용자)

히어로의 사진은 남긴다. 그 아래는 히어로를 본 사람이 묻는 순서대로 답한다: 무엇을
하는가(`#december`) → 무엇이 남는가(`#gains`, 신설) → 그게 진짜인가(`#record`) → 누가
만드는가(`#naru` 이후).
