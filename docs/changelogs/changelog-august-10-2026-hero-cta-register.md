# Changelog — August 10, 2026 (히어로 주 CTA를 등록으로)

**Project:** Builderthon marketing site (Next.js)
**Branch:** `main`
**Scope:** `components/journey/Journey.tsx` — 모듈 상수 `HERO_PRIMARY`,
히어로 CTA 클러스터. 그 외 파일 변경 없음.

## 문제

모바일 첫 화면에 **등록 진입점이 하나도 없었습니다.**

- 히어로 주 CTA = "8일의 여정 둘러보기" (프로그램 섹션으로 스크롤)
- 등록 버튼을 가진 모바일 스티키 바는 **히어로 구간에서 숨겨집니다** — 그 구간의
  CTA는 히어로 자신이 맡는다는 전제였는데, 정작 그 CTA가 등록이 아니었습니다.
- 네비의 등록 버튼은 lg 미만에서 렌더되지 않습니다.

모집 초기에는 맞는 설계였습니다("뭘 하는 행사인지부터 보여주고 등록"). 등록 마감
국면에 들어선 지금은 첫 화면이 곧장 등록을 밀어야 합니다.

## 1. 상수 스위치 — `HERO_PRIMARY`

```ts
// 모집 국면별 히어로 모드 — "journey"=둘러보고 등록(모집 초기), "register"=곧장
// 등록(마감 임박, 8/10 전환). 되돌릴 땐 이 한 줄만.
const HERO_PRIMARY: "journey" | "register" = "register";
```

되돌리기가 한 줄이어야 하는 이유: 이건 디자인 결정이 아니라 **국면 결정**입니다.
다음 기수 모집 초기에는 다시 `"journey"`가 맞고, 그때 코드를 다시 짜게 만들면
안 됩니다. 그래서 journey 모드의 마크업을 지우지 않고 분기로 남겼습니다.

## 2. `register` 모드 (새 기본값)

| 자리 | 전 (journey) | 후 (register) |
|---|---|---|
| 주 CTA (보라 그라디언트) | 8일의 여정 둘러보기 | **등록하기** → `openRegister()` |
| 보조 (고스트) | 파트너십 문의 (`md:hidden`) | 8일의 여정 둘러보기 |
| 보조 (고스트, `lg:hidden`) | 오픈채팅 | 오픈채팅 (그대로) |

- **등록 상태 처리**는 네비·푸터의 기존 관례를 그대로 씁니다: 이미 등록한
  방문자에게 라벨이 `dict.register.navRegistered`로 바뀌고 화살표가 빠집니다(갈
  곳이 없으니까). 클릭은 계속 열립니다 — 등록 정보를 다시 보려는 사람에게 문을
  잠글 이유가 없습니다.
- **트래킹**: `track("register_click", { src: "hero" })` — 기존 `openchat_click` ·
  `quiz_click`과 같은 `{src}` 패턴입니다. 이 이벤트 이름은 이번에 처음 생겼고,
  히어로가 첫 사용처입니다.
- **파트너십 문의는 히어로에서 뺐습니다** (register 모드에서만). 학생 등록 마감
  국면에 첫 화면 버튼 자리는 등록·여정·오픈채팅 셋이면 충분하고, 넷째가 붙으면
  375px에서 줄이 하나 더 접히며 주 CTA의 무게가 흩어집니다. 기업용 문의 창구가
  사라지는 것은 아닙니다 — 클로징 섹션과 푸터가 같은 링크를 그대로 갖고 있고,
  원래도 `md:hidden`이라 데스크톱에서는 보이지 않던 버튼입니다.

## 3. 건드리지 않은 것

- **스티키 바·네비**: 동작 무변경. 스티키 바가 히어로 구간에서 숨는 규칙도
  그대로입니다 — 이제 그 구간의 등록 CTA를 히어로가 실제로 갖고 있으므로,
  전제와 구현이 처음으로 맞아떨어집니다.
- **등록 훅 카드**("팀이 없어도 괜찮아요 — 등록하고 팀 매칭 받기"): 그대로 둡니다.
  주 CTA와 같은 행동을 두 번 노출하지만 **의도된 중복**입니다 — 훅 카드는 솔로
  매칭 프리셋(`{ joinType: "solo", wantsMatching: true }`)을 담고 있어서 여는
  모달의 상태가 다릅니다.
  렌더해서 확인한 결과 위계 조정도 불필요했습니다:

  | 버튼 | 높이 | 글자 |
  |---|---|---|
  | 히어로 주 CTA | 65px | 18px |
  | 네비 등록 (lg+) | 45px | 15.75px |
  | 훅 카드 등록 | 44px | 15.75px |

  셋이 한 화면에 보이는 것은 데스크톱뿐이고, 거기서도 크기와 담긴 그릇(히어로
  본문 / 네비 바 / 테두리 있는 글래스 카드)이 달라 주 CTA가 분명히 앞섭니다.
  모바일에서는 훅 카드가 파트너 스트립 한 화면 아래에 있어 둘이 같은 뷰포트에
  들어오지도 않습니다.
