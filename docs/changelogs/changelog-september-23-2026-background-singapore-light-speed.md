# Changelog 2026-09-23 (싱가포르 빛의 폭과 속도 상한)

**Scope:** `lib/background/config.ts`, `scene/BackgroundScene.ts`, `shaders/water.ts`, `water/WaterSurface.ts`. 파문은 바꾸지 않았습니다.
**근거:** `docs/background-singapore-light-speed-brief.md`

- 폭: `LIGHT_SWEEP` 0.12(가로) / 0.15(세로), 셰이더 상수를 `uSweep` 유니폼으로.
- 속도: `s4Eased`의 초당 변화에 상한 `LIGHT_MAX_RATE` 0.05.
- 브리프에 없던 한 가지: 셰이더의 uv 폭은 화면 폭이 아니라 수면 평면의 폭입니다(화면보다 12% 넓고 카메라 돌리로 조금 더). 0.12가 화면 폭의 0.136(폰 0.15가 0.179)으로 그려져서, 평면의 두 끝을 매 프레임 투영해 나눕니다. 그래서 `LIGHT_SWEEP`은 실제 화면 폭 대비입니다.
