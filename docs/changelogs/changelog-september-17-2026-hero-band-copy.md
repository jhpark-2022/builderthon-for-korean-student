# Changelog 2026-09-17 (히어로 형상 띠, 언론 줄 정렬, 12월 카피)

## 1. 문제 (사용자, 프로덕션 캡처 넷)

1. 2000×1100 화면에서 싱가포르·서울 형상이 "너무 화면 아래에" 있었습니다. 히어로는
   가운데 뜨고 형상만 바닥에 붙어 있었습니다.
2. 형상이 처음 2초쯤 늦게 떴습니다.
3. 언론 줄의 제목 길이가 줄마다 크게 달라(영문 보도자료 두 줄, 한국 기사 한 줄) 가운데
   맞춤이 애매했습니다.
4. "raw data"라는 말을 쓰지 말 것. 이번 회차는 "데이터에서 시작한다". AI의 쓰임 셋
   (아이디어의 코드화, 복잡한 비즈니스 프로세스 이해, 다량의 데이터 분석) 중 8월은
   첫 번째에 집중했고 12월은 넓힌다.
5. 8월에 아쉬웠던 넷의 12월 답: 02는 멘토링의 사전 디테일을 더 공유한다로, 03은 모든
   활동을 대면으로 한다로.

## 2. 결정

- **형상은 히어로 레이아웃의 일부.** 히어로 그리드 아래에 띠(`data-shape-anchor="band"`)
  를 모든 폭에 두고 형상은 그 안에 섭니다. 데스크톱 띠 높이 min(20vw, 24vh), 폰 150px.
  띠가 레이아웃에 있어야 히어로(카피 + 패널 + 형상)가 한 덩어리로 가운데 잡히고,
  형상이 카피·패널 바로 아래에 옵니다. 2차의 "남는 공간에 놓기"와 감광 규칙은 뺐습니다.
  얕은 노트북(1280×720)에서는 띠가 첫 화면 아래로 조금 내려갑니다(형상 윗부분만 보임).
- **배경을 더 일찍, 라벨은 배경과 같이.** `Background.tsx`의 idle 대기 상한 1500 →
  400ms. 씬이 시작하면 `naru:bg-ready` 이벤트를 보내고 `ShapeLabels`는 그때 700ms
  페이드로 뜹니다. 라벨(DOM)만 먼저 뜨던 것이 "형상이 늦다"로 보이던 부분이었고, 실제
  배경 시작도 1초쯤 당겨졌습니다.
- **언론 줄은 표 정렬.** 제호(9rem) · 제목(가변) · 날짜(5.5rem) · 링크(5.5rem) 네 열,
  왼쪽 맞춤. 폰에서는 세로로 쌓입니다. 보도자료 줄은 제호 칸에 CNA · The Straits Times
  링크 둘. `components/shared/PressRows.tsx`. Journey.tsx 원문 불변.
- **카피.** 히어로 서술: "이번에는 데이터에서 시작합니다. 문제를 찾아내는 것부터 앞에서
  증명하기까지, 닷새." 12월 제목: "데이터에서 증명까지, 닷새". 12월 첫 문장(shapeLead):
  AI의 쓰임 셋 → 8월은 첫 번째 → 12월은 나머지 둘로. 그 밖에 "raw data"가 있던 자리
  (gaps[0] 답, shape[1] note, 학생회와 기업의 한 줄, 화면에 없는 changes[1])도 "데이터"로.
  영어도 같이. 주석 속의 "raw data"는 그대로(역사).
- **12월의 답.** 02 "멘토링의 디테일을 사전에 더 많이 공유합니다." 03 "이번에는 모든
  활동을 대면으로 합니다." 이전 문장(상시 예약제 · 횟수 무제한, 팀 본딩 · 중간 공유)은
  일정 블록이 이미 말하고 있어 잃는 정보가 없습니다.
