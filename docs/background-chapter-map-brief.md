# 배경 브리프: 형상을 챕터에 맞춥니다

대상 레포: `website` (커밋 `ee40f00` 기준). 바꾸는 파일은 `lib/background/config.ts`와 `lib/background/scene/BackgroundScene.ts`, 필요하면 `shaders/particles.vert.ts`입니다. DOM, 카피, 라우트, 수파베이스, `/2026-08`은 건드리지 않습니다.

계측 대상: https://naru-crossing-seoul.vercel.app/ (1440×900 문서 10,499px, 390×844 문서 12,871px). 챕터 앵커와 h2 위치를 실측해 각 구간이 어느 챕터 위에 놓이는지 계산했습니다.

## 0. 결론 한 줄

해가 지는 효과는 좋은데 **너무 오래, 그리고 서울의 자리에** 걸려 있습니다. 그 결과 서울이 온전히 서 있는 구간이 **0px**이고, 싱가포르는 3.8화면(폰 5.1화면)입니다. 형상을 챕터의 뜻에 맞춰 다시 놓습니다.

## 1. 지금 무엇이 어디에 있나

### 1.1 실측 (데스크톱)

| 나루터(수면, 해) | 0 → `#top` 하단 | 0 → 1,037 | 1,037 | 히어로 |
| **해가 내려가 점이 됨** | `#top` 하단 → `#gains` 상단 | 1,037 → 4,345 | **3,308** | **`#december` 전체** (데이터에서 증명까지, 닷새) |
| 서울 떠오름 | `#gains` 상단 → +0.8vh | 4,345 → 5,065 | 720 | `#gains` |
| 건너기 시작 | `#naru` − 0.5vh | **4,795** | | 떠오름이 끝나기 **270px 전** |

### 1.2 무엇이 어긋났나

**첫째, 서울 이벤트 챕터에 서울이 없습니다.** `#december`는 크로싱 서울의 프로그램, Day 0~4, 세션, 8월에 아쉬웠던 것입니다. 3,308px 내내 배경은 해가 내려가는 장면입니다. 좋은 장면이지만 이 챕터의 것이 아닙니다.

**둘째, 서울이 서 있을 자리가 없습니다.** 9월 23일 시계 브리프에서 서울의 등장을 `#gains`로 옮겼는데 건너기의 시작(`#naru` − 0.5vh)은 그대로였습니다. 그래서 서울은 떠오르는 중에 이미 건너기 시작합니다. 온전히 선 순간이 한 프레임도 없습니다.

**셋째, 싱가포르가 마지막 챕터까지 서 있습니다.** `#join`은 "왜 이 자리가 필요한가"이고 그 안이 **싱가포르에서 / 한국에서 / 그 밖의 나라에서** 셋입니다. 세 곳을 나란히 두는 챕터 뒤에 싱가포르 하나만 서 있으면 셋 중 하나를 편드는 그림이 됩니다. 이 챕터가 하는 말은 "어느 한 기슭"이 아니라 "건너는 자리"입니다.

## 2. 챕터에 맞춘 지도

앵커로 적습니다. 카피가 늘어도 챕터를 따라갑니다.

| 구간 | 앵커 | 배경 | 데스크톱 길이 | 폰 길이 |
| --- | --- | --- | --- | --- |
| 0 나루터 | 0 → `#top` 하단 | 수면, 해 | 1,037 | 1,218 |
| 1 건넘 | `#top` 하단 → **+1.2vh** | 해가 내려가 나루 점이 됨 | 1,080 | 1,013 |
| 2 서울 | 구간 1 끝 → `#naru` − 0.5vh | 서울 윤곽 | **2,678** | **4,243** |
| 3 크로싱 | `#naru` − 0.5vh → +1.0vh | 서울 → 싱가포르 | 1,350 | 1,266 |
| 4 싱가포르 | 구간 3 끝 → **`#join` 상단** | 싱가포르 윤곽 | **2,435** | **2,573** |
| 5 세 곳 | `#join` 상단 → 끝 | **형상이 흩어지고 나루 점만 남음** | 1,519 | 2,145 |

서울 : 싱가포르가 데스크톱 1 : 0.91, 폰 1 : 0.61이 됩니다.

### 2.1 왜 이렇게 나누나

- **구간 1을 1.2화면으로.** 해가 내려가 점이 되는 데 3.7화면은 필요 없습니다. 히어로(구간 0)에서 이미 한 화면을 해와 보냈고, 1.2화면이면 내려가는 것이 다 보입니다. 1.5까지는 괜찮고 그 위로는 서울을 깎습니다. `config.ts`에 값을 두고 사용자가 고를 수 있게 합니다.
- **구간 2가 `#december`의 대부분과 `#gains` 전체.** 크로싱 서울의 프로그램과 얻는 것을 읽는 동안 서울이 서 있습니다.
- **구간 3은 그대로.** `#naru`의 제목 "건너는 건 각자가 한다"(y 5,746)가 건너기의 70% 지점에 옵니다. 제목이 건넘을 말할 때 형상이 건너고 있습니다. 우연이지만 맞는 우연이라 지킵니다.
- **구간 4가 `#naru` 챕터.** 그 안에 `#record`(8월이 남긴 것, 싱가포르에서)가 y 6,267에 있고, 싱가포르는 6,145에 도착합니다. 8월 이야기를 읽을 때 싱가포르가 서 있습니다.
- **구간 5에서 형상을 거둡니다.** 세 곳을 말하는 챕터에는 한 기슭이 아니라 나루 점 하나만 둡니다. 매니페스토의 마지막 문장이 이 자리입니다. "건너간 사람이 다시 돌아와 서는 자리도 같은 나루다."

## 3. 실행

### 3.1 `config.ts`

`SEOUL_WATERMARK`에 구간 경계를 모읍니다. 흩어져 있던 `revealVh`, `morph`를 여기로 옮기고 새 값 둘을 더합니다.

```ts
  // ── 구간 지도 (DECIDED 2026-09-23, 챕터 지도 브리프) ─────────────────────
  // 앵커는 BackgroundScene.readAnchors가 읽습니다: #top 하단, #naru, #join.
  // 카피가 늘어도 챕터를 따라갑니다. 각 구간이 어느 챕터 위에 놓이는지는
  // 브리프 2장의 표에 있고, 그 표가 이 값들의 이유입니다.
  stages: {
    // 구간 1: 해가 내려가 점이 됩니다. #top 하단부터 이만큼(뷰포트 높이 배).
    // 전에는 #gains 상단까지였는데, 그러면 #december(서울 이벤트 프로그램) 전체가
    // 해가 지는 장면이었습니다. 1.2면 내려가는 것이 다 보입니다. 1.5까지 괜찮습니다.
    descendVh: 1.2,
    // 구간 2: 서울. 구간 1 끝에서 이만큼에 걸쳐 떠오른 뒤, 건너기 시작까지 섭니다.
    revealVh: 0.6,
    // 구간 3: 서울 → 싱가포르. #naru 위쪽 startVh 앞에서 시작해 spanVh 동안.
    morph: { startVh: 0.5, spanVh: 1.5 },
    // 구간 5: 형상을 거둡니다. #join 상단에서 이만큼에 걸쳐 0으로.
    // 세 곳(싱가포르·한국·그 밖)을 말하는 챕터 뒤에 싱가포르 하나만 서 있으면
    // 셋 중 하나를 편드는 그림이 됩니다. 나루 점만 남깁니다.
    dissolveVh: 1.0,
  },
```

`calmBright`는 지웁니다. 구간 5가 그 일을 대신하고, 구간 4는 온전한 밝기입니다.

### 3.2 `BackgroundScene.ts`

`readAnchors`에 `#join` 상단을 더합니다. water 분기의 구간 계산을 이렇게 바꿉니다.

```ts
      const S = W.stages;
      const descendEnd = this.heroEnd + S.descendVh * vh;
      const s1 = ss(clamp((this.scrollY - this.heroEnd) / (S.descendVh * vh), 0, 1));
      const reveal = ss(clamp((this.scrollY - descendEnd) / (S.revealVh * vh), 0, 1));
      const morphStart = this.naruTop - S.morph.startVh * vh;
      const morph = ss(clamp((this.scrollY - morphStart) / (S.morph.spanVh * vh), 0, 1));
      const dissolve = ss(clamp((this.scrollY - this.joinTop) / (S.dissolveVh * vh), 0, 1));
      const shapeOpacity = reveal * (1 - dissolve);
```

`calm`을 쓰던 자리는 전부 `dissolve`로 바꿉니다. `uStage1`에는 `s1`을, `setMorph`에는 `morph`를 그대로 넘깁니다.

**구간 2가 음수가 되지 않게 지킵니다.** `morphStart < descendEnd + S.revealVh * vh`이면(챕터가 너무 짧아 서울이 설 자리가 없으면) 개발 빌드에서 경고를 찍으세요. 지금 배포된 상태가 정확히 그 경우였고, 아무도 몰랐습니다.

### 3.3 구간 5의 모양 (선택)

`shapeOpacity`를 0으로 내리는 것만으로 형상은 사라집니다. 거기에 **흩어지는 느낌**을 더하려면 버텍스 셰이더의 `uBreath`를 `dissolve`에 따라 0.3 → 1.6으로 올리세요. 점이 제자리에서 느슨해지며 옅어집니다. 새 경로를 만들지 말고 있는 `uBreath` 유니폼만 씁니다. 이건 선택이고, 먼저 불투명도만으로 배포해서 보고 정해도 됩니다.

### 3.4 나루 점은 그대로

구간 5에서 형상이 사라져도 나루 점(water 셰이더의 깊은 물 층)은 남습니다. 지금 코드가 이미 그렇게 되어 있습니다. 건드리지 마세요. 점이 화면 위로 올라오는 `my`의 이동도 그대로입니다.

## 6. 사용자가 정할 것

1. **구간 1의 길이.** 1.2화면으로 적었습니다. 해가 지는 것을 더 오래 보고 싶으면 1.5까지. 그 위로는 서울이 깎입니다.
