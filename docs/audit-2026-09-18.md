# 나루 홈 비주얼 감사 (2026-09-18, 프로덕션)

대상: https://builderthon-for-korean-student.vercel.app (커밋 `ed25b4e`). 데스크톱 1440×900 12프레임, 모바일 390×844 17프레임을 찍고, `Vibe Code/subagents`의 페르소나 8종(ui-designer, mobile-ux-optimizer, ux-researcher, brand-guardian, visual-storyteller, whimsy-injector, accessibility-expert, web-dev)이 각자 관점으로 같은 프레임을 봤다. 아래는 8개 보고서를 합치고 겹치는 것을 묶은 것이다.

**제외한 것 하나.** 여섯 페르소나가 "데스크톱 프레임 3·7이 완전히 비어 있다, 8월 숫자·언론이 데스크톱에 없다"를 P0으로 올렸다. 재확인 결과 **캡처 오류**다. `html { scroll-behavior: smooth }`가 걸려 있어 프로그램 스크롤 뒤 0.7초 대기로는 스크롤이 끝나지 않았다. 대기를 늘리니 전부 그려진다. 실제 사이트 문제가 아니므로 뺐고, `scroll-behavior`는 web-dev 항목에 작게 남겼다.

## 2. P1

**내용·흐름**
- 히어로가 "나루의 다음 이벤트"라고만 해서 나루를 모르는 사람에게 나루가 뭔지 없다 (ux-researcher; mob-00). → 아이브로 또는 서술 첫 줄에 "싱가포르에서 시작한 한인 학생 빌더 커뮤니티" 한 문장.
- 기업 담당자에게 **얻는 것**이 없다. 내는 것(문제·자료·자금·멘토)과 "법인격 없음, 돈 직접 안 받음"이 먼저 보인다 (ux-researcher; desk-09, mob-12, mob-14). → 기업 카드에 8월 출제사가 실제로 받은 것 두 줄(9팀이 직접 자료 요청, CNA·ST 노출).
- 8월 참가자를 위한 "8월을 건넌 분께"가 17프레임 중 15번째이고 8월 챕터에서 그리로 가는 연결이 없다 (ux-researcher; mob-15). → 8월 챕터 끝에 "8월에 오셨던 분은 →" 앵커.
- "제로백 빌더톤의 2회차가 아닙니다"(프로그램)와 "나루의 첫 이벤트"(8월)가 순서상 충돌해 관계가 헷갈린다 (ux-researcher; mob-01, mob-06). → 한 문장으로 통일: "나루의 두 번째 이벤트. 제로백의 속편은 아닙니다."
- 히어로 사진 4장에 캡션이 없어 12월 사진처럼 읽힌다 (visual-storyteller, whimsy; desk-01, mob-00). → "제로백 빌더톤 · 2026.08 싱가포르" 한 줄 캡션(호버 시 슬라이드도 가능).
- 8월 숫자 74→59→25→21→9는 깔때기인데 같은 크기 타일 5개로 나열되고, 핵심인 "9팀 · 시키지 않았습니다"가 가장 작다 (visual-storyteller; mob-07). → 스텝 차트 한 줄 + 9팀을 큰 숫자로. 모바일 3+2 그리드의 높이 불일치도 같이 해결.
- 데스크톱에 노선도가 없고 Day 카드 5장 + 참여 플로우 4상자가 같은 시간축을 두 번 그린다 (visual-storyteller; desk-02, desk-04). → 확인 필요: 노선도가 데스크톱에서 렌더되는지. 렌더된다면 참여 플로우 삭제, 아니면 노선도 복구.
- 얻는 것 카드 5장 높이가 같은데 "멘토"는 두 글자라 빈 카드처럼 보인다 (ui, mobile-ux; desk-05, mob-06). → 카드 높이를 내용에 맞추고 최소 높이만 통일, 모바일은 1열 리스트 행 64px.

**브랜드·시각**
- Day 카드 강조색이 카드마다 다르다(BEFORE 노랑, Day 1·2 민트, Day 3 분홍, ★ 제출 칩 핑크) (brand; desk-02, mob-02~03). → 강조는 흰색 볼드 하나, 제출 칩만 자주.
- 아이브로 4종 혼용(보라 외곽선 / 주황 외곽선 / 민트 채움 / 보라 채움) (brand). → 보라 외곽선 1종.
- 보조 버튼 크기 3종, 함께 챕터에 외곽선 버튼 5개 (brand; desk-11, mob-14~15). → 보조 버튼 1사이즈, 문의 넷은 텍스트 링크로.
- 원형 인장(KOREAN STUDENT BUILDERS · NARU · SINGAPORE)이 헤더 워드마크와 다른 두 번째 로고로 읽힌다 (brand; mob-08~09). → 보조 마크로 규정하고 크기를 줄이거나, 영문 표기 하나로 확정.
- 나루 챕터가 텍스트만 4.4화면(모바일) (visual-storyteller, mobile-ux). → 코어 둘은 아이콘 + 한 문장, 3층 다이어그램에 "하지 않는 것"을 각주로.

**접근성·구현**
- 12px 미만 텍스트 44개, 저채도 회색·분홍이라 4.5:1 미달 의심 (a11y, WCAG 1.4.3). 텍스트 링크 12개 히트 높이 17~23px (a11y, WCAG 2.5.8). 모바일 브리프 4·5장과 같다.
- 배경 정지 토글이 푸터(모바일 15화면 아래)에만 있다. 데스크톱 푸터에는 없는 것으로 보임(확인 필요) (a11y, whimsy, web-dev; mob-16, desk-11). → 헤더로 복제, 선택은 localStorage.
- EN/KR 현재 상태가 색만으로 구분 (a11y, WCAG 1.4.1). → 밑줄 또는 굵기 + `aria-current`.
- 카운트다운이 `aria-live`면 분마다 낭독, 숫자와 단위가 분리돼 "81 일"로 읽힘 (a11y, WCAG 4.1.3). → 컨테이너 `aria-label` 하나로.
- 히어로 사진 `sizes` 미지정으로 dpr 3 기기에서 흐림 가능, `src` 없는 `<img>` 하나, 모바일 로드에서 리소스 502 한 건 (web-dev). → `sizes="(max-width: 640px) 45vw, 230px"`, 위 두 장 `priority`, src 없으면 렌더 안 함, 502 URL 확인.
- 메타: title에 이벤트 키워드 없음, 영문 description에 `og:locale ko_KR`, `alternates.languages` 없음 (web-dev). → `title.default: "크로싱 서울 2026 | 나루 NARU"`, 로케일별 description.
- `html { scroll-behavior: smooth }`는 앵커 클릭 핸들러의 `scrollIntoView({behavior:"smooth"})`로 옮기고 html에서는 뺀다 (web-dev). 이번 캡처 오류의 원인이기도 하다.

## 3. 선택 사항 (whimsy, 구현 난이도 낮음)

- 노선도의 주황 점 하나가 현재 읽는 Day 카드 위치로 노선을 따라 이동, 제출일 별은 지날 때 한 번 밝아짐. 점은 하나만.
- 8월 숫자 뷰포트 진입 시 0→값 카운트업 600ms, 한 번만. reduced-motion이면 생략.
- 히어로 사진 호버·롱프레스 시 하단 캡션 슬라이드(위의 캡션 항목과 겸함).
- 놀이로 만들면 안 되는 곳: 아쉬웠던 넷, 하지 않는 것, 미정 목록, 언론 카드, 비활성 등록 버튼. 사실만.

## 4. 잘 된 것 (여러 관점 합의)

- 챕터마다 캡슐 라벨 → 큰 제목 → 카드의 리듬이 일관되고, 남색 배경·Pretendard·입자 배경이 끝까지 이어져 한 브랜드로 읽힌다.
- 첫 화면의 훅(이름, 기간, 포지션, 사진 4장, 카운트다운)이 "다음 이벤트가 있다"를 즉시 말한다.
- 노선도 5정거장이 390px 한 줄에 들어가고, Day 카드의 "→ 그날의 한 줄", 3층 카드, 배지가 데스크톱과 같은 토큰으로 일관된다.
- 로고는 사진 위에 올라가지 않고 헤더·푸터에서만 같은 비율로 쓰인다. 푸터의 배경 정지 토글은 좋은 배려다.
